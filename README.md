I am a **Software Development Engineer** passionate about building scalable, high-performance web applications. I specialize in backend architecture, database optimization, and modernizing legacy systems to support rapid growth.

My focus is on writing clean, efficient code and solving complex engineering challenges—whether it's optimizing slow database queries, designing robust APIs, or building seamless full-stack user experiences.

### 🚀 What I Do

* **Backend Architecture:** Designing and maintaining robust server-side applications using **Node.js** and **PHP**.
* **Performance Engineering:** Optimizing system performance through efficient database design (**SQL & NoSQL**), caching strategies (**Redis**), and search implementation (**Elasticsearch**).
* **Full Stack Development:** Bridging the gap between complex backend logic and modern frontend frameworks like **Next.js** and **React**.
* **System Scalability:** Building systems that handle high traffic and large datasets with minimal latency.
* **Automation:** streamlining workflows and third-party integrations to improve operational efficiency.
